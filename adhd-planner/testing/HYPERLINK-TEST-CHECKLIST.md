# Hyperlink Test Checklist — ADHD Reset Planner

Tap through the **actual PDF on your iPad** (GoodNotes, then Notability) and tick
each link. Pulled directly from the final build's link structure — not the spec.

## How to use
1. Import the PDF **as a document** (not "as image") into GoodNotes.
2. Make sure a **pen/eraser tool is NOT active** while tapping (use the Hand/
   Pointer tool) so taps follow links instead of drawing.
3. Work top to bottom. Tick Pass or write what went wrong on the Notes line.
4. Repeat the whole sheet for the **Dark** file, then (ideally) redo in Notability.

# 🛠 If you find a broken link — what to send me

For each broken link, note these 5 things so I can fix it fast:

1. **File:** Light or Dark (and app: GoodNotes / Notability)
2. **Page + link text:** e.g. "Page 8, 'I'm bored → make it shorter…'"
3. **Expected destination:** e.g. "Page 10 (Reward Chart)"
4. **What actually happened:** one of —
   - jumped to the **wrong page** (say which page it landed on)
   - **no response** to the tap
   - **worked but slow / needed several taps**
   - jumped but to the **wrong spot on the right page** (e.g. middle instead of top)
5. **Tap target feel (optional):** was the tappable area smaller/larger than the
   text? (helps me resize the link hotspot)

Fastest path: copy the checklist line that failed and add "→ actually did X."
A screen-recording of the mis-tap is gold but not required.

> Note: nearly all real-world link issues are import-side, not the file —
> if a link fails, first retry after (a) re-importing as a **document**, (b)
> updating the app, (c) switching off the pen tool. If it still fails after that,
> send it over and I'll adjust the actual link in the build.
