## Description (paste this into the Description field)

Tested to actually work — every hyperlink, every time. No broken links, no
setup stress. Just tap and go.

If you've bought a "gentle" ADHD planner before and then spent an hour fighting
the import, hunting for pages, or tapping links that went nowhere — you already
know the problem. The calm promise on the outside, the friction on the inside.

This one is built the other way around.

⚡ WHY IT'S DIFFERENT

• Energy-based planning — Check in with your energy first, then tap through to a
  task list that matches it. Low battery day? You get five-minute, impossible-
  to-fail wins. Full battery? Batch mode. The planner meets you where you are.

• Hyperlinks that actually work — A top navigation bar on every page, plus
  functional links that take you straight to the right tool (not just page
  flips). Every single link was verified before this went on sale.

• Guilt-free by design — No streaks to break. No red X. No day marked as a
  failure. The habit tracker uses two soft stamps: GOOD (did it) and it's okay
  (didn't) — because rest counts too.

• Near-zero setup — One file, import, done. No account, no add-ons, no template
  stitching.

🔁 UNDATED & REUSABLE

This is a template set — one clean copy of each page (Check-In, Brain Dump, Habit
Tracker, and more), with no dates pre-printed. Start any day, any month. When you
want a fresh page, duplicate it in your app in one tap (fully explained in the
included guide) — so it works for you indefinitely, not just for one calendar year.

📦 WHAT'S INCLUDED (instant digital download)

• Light PDF — the full planner (Mindset, Check-In, Brain Dump, Energy Task
  Banks, Task Breakdown, Focus Plan, Habit Tracker, Reward Chart, Monthly, and
  more)
• Dark PDF — the same planner in a night-friendly dark theme
• 4 habit stamp stickers (transparent PNG) — GOOD + it's okay, drag & drop
• A sticker sheet for copying stamps inside your app
• Start-Here quick-start guide (illustrated, 60-second setup)
• README with per-app help & troubleshooting

📱 DEVICE COMPATIBILITY (please read — this matters)

• Best on an iPad with GoodNotes 5/6 or Notability (v11+). This is what the
  planner is designed for.
• Android / Windows: works great in Xodo (free) and most PDF apps that support
  internal links.
• You need a PDF annotation app that supports hyperlinks — the links are
  standard PDF links, nothing proprietary. A stylus (Apple Pencil, etc.) is
  recommended but not required.
• This is a DIGITAL download — no physical item ships. Because it's instant and
  digital, all sales are final, but if anything doesn't work, message me and
  I'll help you get it running.

💡 Tip: In GoodNotes, switch to Read-Only mode (top-right pencil icon) for instant
one-tap navigation. In edit mode, links need a long-press + "Open Link" — this is
a GoodNotes app behavior, not a planner issue.

💛 A NOTE FROM ME

You don't have to use every page, every day. Open it on the days you can, skip
the parts that don't help. This is a small guide for getting back up — not one
more thing to be perfect at. Be gentle with yourself. Rest counts too. 🌿
