# 15-Second Etsy Listing Video — Script & Storyboard

**Purpose:** Etsy's gallery video slot (5–15s). One job: *prove the hyperlinks
work.* A shopper should see a finger tap the nav bar and the page jump — that's
the whole sell.

**Specs**
- Length: **15 seconds** (hard cap for Etsy).
- Orientation: **square 1:1** (Etsy crops video to square) — frame the iPad so
  the planner fills the square. Vertical 9:16 also fine if you'll reuse it on Reels.
- **Silent-friendly:** no narration. Big text overlays only (many shoppers
  autoplay muted). Optional soft lo-fi music underneath.
- Capture: **iPad screen recording** (Control Center → Record). Turn on touch
  indicators so the taps are visible — Settings, or use AssistiveTouch, so each
  tap shows a dot. Record at 60fps.

---

## The 15 seconds, shot by shot

| Time | What's on screen | Text overlay (large, top or bottom) |
|---|---|---|
| 0.0–2.0s | Planner open on the **Check-In** page, sitting still. Clean, cream. | **Every link actually works.** |
| 2.0–4.5s | Finger/pencil taps **"Brain Dump"** in the top nav → page jumps instantly. Show the tap dot land. | *Tap the top bar…* |
| 4.5–7.0s | Tap **"To-Do"** → jumps to the Energy Bank. Then tap **"Tasks"** → jumps to Task Breakdown. Quick, snappy cuts on each jump. | *…land exactly where you need.* |
| 7.0–9.5s | Back on **Check-In**, tap **"tap for full Low Energy Bank"** → jumps to the Low Energy list. | **Low energy? Get low-energy tasks.** |
| 9.5–12.0s | On the **Habit Tracker**, drag a green **GOOD** stamp onto a cell, then a lavender **it's okay** stamp. | **No streaks. No red X.** |
| 12.0–15.0s | Cut to end card: cream background, wordmark, formats line. Hold. | **ADHD Reset Planner** · GoodNotes · Notability · Xodo |

## Storyboard notes

- **Frame the tap.** The single most persuasive moment is a visible finger tap →
  instant page change. Make sure the tap indicator dot is ON so viewers see the
  cause and effect. If you can, hold on the destination page for ~0.3s so the eye
  registers "it landed."
- **Keep it calm, not frantic.** Even at 15s, don't rush the cuts to a blur —
  crisp single taps read as "reliable," which is the brand. Aim for ~5 clean
  taps total across the clip.
- **Two beats only:** (1) links work, (2) it's guilt-free. Don't try to show more.
- **End card** should match the planner: cream `#FBF7EF`, ink text `#3E4A54`,
  a soft green underline. Wordmark "ADHD Reset Planner."
- Optional first-frame **thumbnail poster:** the Check-In page with the overlay
  "Every link actually works." — this is what shows before playback.

## If you only have 5 seconds (fallback cut)

Use rows 2.0–7.0s only: two nav taps that jump pages, overlay "Every link
actually works." That single proof point is enough for the short slot.
